📋 Schema Improvements Summary

HIGH

1. Stock Reservations

New table to track cart holds, prevents overselling when multiple customers checkout simultaneously. Includes 10-min expiration.

HIGH

2. Optimistic Locking

Added version column to INVENTORY. Detects lost updates when concurrent requests modify stock.

HIGH

3. Coupon Tracking

New COUPON_APPLICATION table links orders to coupons with discount amounts. Audit trail for usage validation.

MEDIUM

4. Audit History

ORDER_STATUS_HISTORY logs all status changes with timestamp & operator. Enables order tracking & SLA reports.

MEDIUM

5. Alert Management

LOW_STOCK_ALERT table tracks inventory warnings. Team can mark resolved to prevent duplicate alerts.

MEDIUM

6. Inventory Separation

New INVENTORY table separates product metadata from stock levels. Tracks qty_available vs qty_reserved.

QUICK WIN

7. Product Fields

Added sku (unique), category to PRODUCT. Enables filtering, external integrations.

QUICK WIN

8. Coupon Types

Added coupon_type field (global / first_order / customer_specific) for flexible promotion strategies.

✅ Implementation Plan:
Phase 1 (Must Have): Stock reservations, versioning, coupon tracking — fixes race conditions & enables atomic orders.
Phase 2 (Should Have): Inventory table, status history, alerts — ops visibility & audit trail.
Phase 3 (Nice to Have): SKU/category, metrics view — analytics ready.
