# Vibe Strike: Order & Inventory Engine

**⚠️ New to the project? Start with [START_HERE.md](START_HERE.md) for a complete onboarding guide.**

## Project Overview
Build a real-time e-commerce backend for order and inventory management with customer storefront and ops dashboard in 4 hours.

**Key Constraint:** Four Use Cases developed **independently & in parallel** by different teams/models, with shared API contracts and database schema.

## Use Cases (4 Independent Streams)

| UC | Name | Owner | Key Deliverable |
|---|------|-------|------------------|
| **UC1** | Browse Products & Place Order | Backend + Frontend | Product listing, atomic order placement, race-condition handling |
| **UC2** | Discounts & Coupon Codes | Backend + Frontend | Coupon validation, discount auto-application |
| **UC3** | Inventory Management & Alerts | Backend + Frontend | Inventory levels, low-stock alerts, restock |
| **UC4** | Order Status Tracking | Backend + Frontend | Order status tracking, ops queue, status updates |

**See detailed specs:** `backend/uc*/README.md`

## Technology Stack (Speed → Success)

**Backend:** FastAPI (Python)
- Auto-generates OpenAPI spec + Swagger UI at `/docs` ✅

**Database:** PostgreSQL (Supabase/Neon/Render)
- Atomic stock update query prevents race conditions (5 min setup)

**Frontend:** React (Vite) + Tailwind CSS
- shadcn/ui components for production-ready UI

## Parallel Development Structure

See: `PARALLEL_DEVELOPMENT.md` (detailed structure for 4-team parallel work)

**Key Folders:**
- `api-contracts/` — Shared API spec (all teams read this)
- `database/` — Shared database schema (all teams use this)
- `backend/uc*/` — Each UC develops independently here
- `frontend/src/pages/uc*/` — Each UC owns its UI pages

## Team Roles

**UC1 Team (Browse & Order)**
- Backend Engineer: Product listing, atomic order creation
- Frontend Engineer: Product pages, cart, checkout UI

**UC2 Team (Promotions)**
- Backend Engineer: Coupon validation, discount calculation
- Frontend Engineer: Coupon input field, promotions list

**UC3 Team (Inventory)**
- Backend Engineer: Inventory levels, low-stock queries
- Frontend Engineer: Ops dashboard, alerts, restock form

**UC4 Team (Tracking)**
- Backend Engineer: Order tracking, status updates
- Frontend Engineer: Order tracking page, ops queue

## Key Constraints
- Real-time stock atomicity via atomic UPDATE query (UC1 + UC3)
- All teams follow `api-contracts/openapi-spec.yaml`
- All teams use shared `database/schema.sql`
- All teams import models from `backend/shared/models.py`
- Client-ready UI quality (use shadcn/ui)
- Complete OpenAPI spec (auto-generated by FastAPI)
- Claude Code usage across full stack
