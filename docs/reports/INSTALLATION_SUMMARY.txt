================================================================================
                      PRODUCTION MIGRATION
================================================================================

To use PostgreSQL in production:

1. Update .env:
   DATABASE_URL=postgresql://user:password@host:5432/vibestrike

2. Install PostgreSQL driver:
   pip install psycopg2-binary

3. Create database:
   createdb vibestrike

4. Run migrations:
   alembic upgrade head

5. Update CORS_ORIGINS for production domain

6. Set DEBUG=false in .env
