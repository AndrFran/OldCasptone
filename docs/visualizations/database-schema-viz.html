📊 Relationships & Constraints

1:N - customers → orders
A customer has many orders. Cascade delete enabled.
1:N - orders → order_items
An order contains multiple line items. Cascade delete enabled.
1:N - products → order_items
A product appears in many orders. Delete restricted (cannot delete product with existing line items).
Soft FK - coupons ← orders
Orders reference coupons via coupon_code (VARCHAR). No enforced foreign key constraint.
Order Status Flow
pending → confirmed → shipped → delivered
Cancellation possible from pending or confirmed states.
Key Indexes
• idx_products_stock – FOR UPDATE locks during atomic order placement
• idx_orders_customer_id – Customer order history queries
• idx_orders_status – Ops dashboard filtering
• idx_coupons_code – Coupon validation lookup
